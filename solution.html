Section 3.2 · System Architecture (Figure 1)

End-to-End Telemetry & Edge AI Pipeline

01 · Biosensing Hub

ECG + Skin Temp

250 Hz single-lead ECG front-end + NTC skin thermistor inside a 3D-printed IP67 reusable hub with disposable hypoallergenic silicone patch.

02 · Edge AI Filter

2-Tier Classification

Bandpass filtering (0.5–40 Hz) + lightweight TinyML model separating benign sinus tachycardia from ST-segment & HRV anomalies.

03 · Encrypted IoT

BLE 5.0 → HTTPS API

24h local flash ring-buffer prevents rural data loss; transmits 30s pre/post-event ECG strips via TLS 1.3 to the Django REST API.

04 · Clinical SaaS

EHR & Triage Portal

EU-hosted HL7 FHIR-ready SaaS dashboard delivering daily summaries and prioritized Tier-1 alerts to cardiologists.

Cloud Computing Architecture · NIST SP 800-145 & 3-Tier Model

Decoupled Database, REST API & Web Interface

Following the NIST SP 800-145 standard (on-demand self-service, broad network access, resource pooling, and rapid elasticity), CardioPatch 4.0 separates persistence, business logic, and presentation into three independent tiers deployed on EU cloud infrastructure (PaaS/IaaS) and delivered to clinics as SaaS (converting hardware CAPEX into scalable OPEX).

Annex C · Hardware & Cloud Specifications

Prototype Bill of Materials & Cloud Stack

C.1 CardioPatch Wearable Sensor Hub

  • Biopotential Front-End: AD8232 / MAX30003 single-lead ECG (250 Hz sampling)
  • Thermal Sensor: Medical-grade NTC thermistor (±0.1 °C accuracy)
  • Protection & Adhesion: IP67 water-resistant + disposable breathable silicone hydrogel
  • Connectivity & Battery: BLE 5.0 · 7-day rechargeable LiPo + 24h offline flash buffer

C.2 CardioCloud Containerized SaaS Stack

  • Backend & Database: Python Django + Django REST API + PostgreSQL (Docker-Compose)
  • Hosting & Compliance: EU-sovereign cloud availability zones · GDPR pseudonymization
  • Security & Interoperability: TLS 1.3, AES-256 at rest, RBAC auth, HL7 FHIR JSON API
  • Service Model: SaaS clinical dashboard (zero on-premise hospital server CAPEX)
