# CardioPatch — Startup Product & Health 4.0 Showcase

Clean, low-stimulation 4-page website built with flat root files for GitHub + Vercel:

- `index.html` — **01 · Overview** (Product showcase, levitating device image placeholder, 3-step daily protection)
- `clinical-needs.html` — **02 · Clinical Needs** (17.9M deaths, €282,000M / 282.000 M€ EU burden, 45% silent heart attacks)
- `why-us.html` — **03 · Why Us?** (Competitor table, stakeholder testimonials, and 4 real-world engineering safeguards)
- `health40.html` — **04 · Health 4.0** (Interactive ECG prototype demo, Health 4.0 wheel placeholder, and Section 3.1 review)
- `styles.css` & `animations.css` — Palette, layout bands, levitation keyframes, rolling buttons, wipes & scroll sweeps
- `data.js`, `shared.js` & `widgets.js` — Centralized data, shared navigation/footer, and live ECG waveform canvas
